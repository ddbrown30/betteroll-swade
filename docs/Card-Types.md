## Power cards

Power cards are identical to most item cards with the addition of Power Point management.

<img src="https://github.com/ddbrown30/betteroll-swade/blob/version_2/docs/img/power.webp" width="400">

The lightning bolt button indicates whether or not PP will be deducted after rolling. 1 PP will be deducted for a failed roll. If the character has the Channeling Edge, a raise will reduce the total cost by 1.

The hand button opens up the Power Point Management window. This window contains a list of all the generic power modifiers as well as all of the modifiers for the specific power. Those modifiers are parsed from the description of the power item itself so if you are not using a paid module for your powers, this will likely be empty.

<img src="https://github.com/ddbrown30/betteroll-swade/blob/version_2/docs/img/pp-management.webp" width="500">

## Soak Rolls

<img src="https://github.com/ddbrown30/betteroll-swade/blob/version_2/docs/img/soak.webp" width="400">

When an actor has been targeted and damaged using the Apply Damage button, the Soak card will appear. This will allow the actor to make a Soak roll to spend a Benny and Soak damage. This will only be available if there are Bennies left to spend.
